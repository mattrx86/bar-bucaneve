# Riferimenti visivi — Chiesa Gotica

Sono stati generati due riferimenti visivi preliminari e archiviati nella Library ChatGPT, nella cartella **/Bar Bucaneve/Chiesa Gotica/**:

- `church_navata_reference.png`: studio panoramico della navata gotica.
- `church_asset_board_reference.png`: tavola di direzione artistica e inventario visivo.

Queste immagini servono come riferimenti artistici, NON sono spritesheet e NON sono asset pronti per il caricamento Phaser. La tavola composita contiene elementi disegnati insieme e non deve essere ritagliata automaticamente come se ogni elemento fosse uno sprite pulito.

Gli asset runtime dovranno essere ridisegnati/esportati in file autonomi, con trasparenza, dimensioni, pivot, baseline e frame documentati. Conservare la coerenza con la densità artistica del progetto (1.5) e con la viewport 384×216.
